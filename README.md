# Nifty Chrome Extension

Chrome extension for [Nifty](https://github.com/xhat/nifty), a macOS download manager ([website](https://nifty.ruoxie.com/)): it hands browser downloads to the Nifty app running on your Mac.

# Version

v0.1.19

## Install

1. Run the Nifty app.
2. Open `chrome://extensions`, enable Developer mode, click "Load unpacked" and select this repository's root.
